# Shattered Crown

A physics-driven medieval open world in the browser (Three.js + Rapier): two warring kingdoms, a contested river front, five castles, two capitals, towns where every building has a furnished interior and a household, rigged animals, ships, carts and a living economy.

**Play:** https://fanaustinca.github.io/shattered-crown/

- `npm run dev` — local dev server (port 8941)
- `npm run build` — type-check + production build
- `npm run test:e2e` — headless Puppeteer smoke suite (set `GPU=1` to use the real GPU)
- `npm run assets` — re-fetch CC0 Poly Haven assets (see `public/assets/CREDITS.txt`)

Press **H** in game for every control. Open the browser console (F12) and type `help()` for dev spawn commands.
